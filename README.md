## About me

Software Engineer and Programmer Analyst with experience building, maintaining and integrating enterprise applications across backend and frontend.

I work mainly with **Java 17, Spring Boot and React**, developing REST APIs, microservice-based solutions, system integrations, authentication and authorization flows, messaging between services, data processing and business functionality.

I also work with **C#, ASP.NET Core, Angular, TypeScript, Docker, RabbitMQ, Keycloak, PostgreSQL, MariaDB, MySQL, MongoDB and Oracle**.

- 🎓 B.Sc. in Software Development
- 🎓 Specialization and M.Sc. in Software Engineering
- 📚 Currently pursuing an M.Sc. in Higher Education Teaching
- 🧭 Interested in software architecture, distributed systems, integration and full-stack engineering
